# k12doc

K12 教材知识文档生产仓库：把 `doc/` 下的教材原件（PDF/pptx/docx，不入库）经 AI 提取与编改，产出符合 Nexora 知识库入库规范的 Markdown 知识文档（`生成稿/`），再通过管理端「文档录入」进入知识库（RAG）。

## 快速上手

**第一步：把教材丢给 AI。** 对 AI（zcode / workbuddy / trae 等）说一句：

> 解析 "doc/高中/高中历史/普通高中教科书·历史必修 中外历史纲要（上）.pdf"

AI 会按 [AGENTS.md](AGENTS.md) 的规范自主完成整条流水线：提取文本 → 定位单元与课文 → 按分层提示词逐单元编改出稿 → 质检 → 合并生成 `生成稿/<学段>/<学科>/<册次>/00-整册合并.md` → 提交推送。中途停下时回复「继续任务」即可接着做；不合格的段落 AI 自行重写，无需逐步审批。

**第二步：管理端入库（人工）。** 知识目录建知识点 → 「文档录入」粘贴生成稿正文 → 预览确认公式与表格渲染 → 入库成功后在对应 md 末尾追加 `<!-- 已入库: 日期, 知识点: ... -->` 并提交。

环境前置只有 Git Bash + Python 3.8+（缺失时 AI 自行解决）；手动提取命令等细节见 [AGENTS.md](AGENTS.md) 第八节。

## 目录

- `doc/` 教材原件（gitignore，永不入库；禁止改名移动）
- `提示词/` 分层提示词体系（通用规范 × 学段 × 学科）
- `生成稿/` AI 产出的知识文档（`00-整册合并.md` 为整册验收基准）
- `提取缓存/` 提取中间产物（gitignore）
- `工具/` 提取与合并脚本

# k12doc

K12 教材知识文档生产仓库：教材 PDF（本地 `doc/`，不入库）→ AI 提取 → AI 按分层提示词编改 → `生成稿/` Markdown → 管理端「文档录入」粘贴入库（Nexora 知识库 RAG）。

## 快速上手（三步）

1. **提取**：`工具/extract.sh "<doc/下pdf路径>" "提取缓存/<学段>-<学科>-<册次>.txt"`
2. **编改**：让 AI 读 `AGENTS.md` + `提示词/` 三件套 + 提取文本，一次一个单元，写入 `生成稿/<学段>/<学科>/<册次>/`
3. **入库**：质检通过后，管理端「知识目录」建知识点 →「文档录入」粘贴正文；入库后在文件末尾加 `<!-- 已入库: 日期, 知识点: ... -->`

详细规范、命名规则、质检清单、禁止行为见 [AGENTS.md](AGENTS.md)。

## 目录

- `doc/` 教材原件（gitignore，永不入库）
- `提示词/` 分层提示词体系（通用规范 × 学段 × 学科）
- `生成稿/` AI 产出的知识文档
- `提取缓存/` pdftotext 中间产物（gitignore）
- `工具/` 提取脚本

# 第五单元·写作 论证要合理

## 摘要
本次写作训练「论证要合理」：写议论文，不管是立论还是驳论，都要摆事实、讲道理，使人信服你的观点。合理的论证要求：选用恰切的论据、运用适当的论证方法、准确阐发论据与观点间的逻辑关联，同时论证结构合理、思路清晰。

## 知识要点

1. **论证要合乎逻辑，观点要一致，概念要统一**。以《创造宣言》为例：先以「有人说」的形式列出错误观点作为批驳的靶子，然后举例论证，以古今中外的名人在平凡单调的环境中创造出不平凡业绩的事例证明其荒谬，最后一针见血指出「平凡单调」只不过是懒惰者的借口——具体事例与尖锐剖析相结合，大大增强了说服力。
2. **材料要能支持论点**，避免论据不相干或论据不足。论据要和论点之间有必然、合理、充分的联系，还要通过必要的分析、阐释使读者明白二者的联系。如《敬业与乐业》提出「凡职业都是有趣味的」的观点后，从四个方面论证，引用孔子的话也都分别做了阐释，以切合论证的需要。
3. **选择恰当的论证方法**。除举例论证和道理论证外，还有对比论证、比喻论证、类比论证等。根据内容需要选择合理的论证方法，能增强说服力，增加表达的丰富性。
4. **论证结构合理，思路清晰**。可以采取设置分论点的形式，从多方面、多角度展开论证；也可以采用「提出问题——分析问题——解决问题」的结构，层层深入展开论证。

## 写作实践（教材题目）

一、《怀疑与学问》指出做学问不要盲从或迷信，要有怀疑的精神。请写一段文字论证这个观点，200 字左右：可用相关事例、名言等材料作为论据；要对材料进行具体分析，不要只是简单的「观点＋材料」。

二、俗话说：「知足常乐。」有的人却说：「知足未必常乐。」围绕「知足与快乐」这一话题，自定立意，自拟标题，写一篇议论文，不少于 600 字：在标题或开头明确表达观点；恰当安排论证结构，层次清晰、逻辑严密；注意分析材料，突出材料对观点的支撑作用。

三、中国有句俗话叫「近朱者赤，近墨者黑」，强调环境对人成长的影响。对此你怎么看？自定立意，自拟题目，写一篇驳论文，不少于 600 字：梳理驳论的写法，选择合适的角度批驳，同时表明自己的观点；材料最好兼有事实论据和道理论据；先列提纲交流补充，再完成作文。

## 例题
思考题：写驳论文「近朱者赤，近墨者黑，环境决定人的成长」，可以怎样批驳？
解答：可从三步入手：①亮出靶子——有人认为环境完全决定人的成长；②驳论据与论证——列举事例证明同处一境而成就迥异的例子（如同一师门出高徒与庸才、逆境出人才者比比皆是），说明环境只是外因；③立己论——内因（理想信念、自律与努力）才是成长的决定因素，环境有影响但不决定；并用「出淤泥而不染」等事例与道理论证观点。批驳时注意观点一致、概念统一，论据与观点之间要有必然联系并加以分析。

## 练一练
1. 判断题：驳论不属于论证，因为它是反驳别人的观点。（　）
2. 填空题：论证方法除了举例论证和道理论证之外，还有对比论证、（　　）论证、类比论证等。
3. 简答题：使论证结构合理的两种常见做法是什么？

## 参考答案
1. 错（驳论也是一种论证，只不过是论证对方论点不正确）
2. 比喻
3. 一是设置分论点，从多方面、多角度展开论证；二是采用「提出问题——分析问题——解决问题」的结构，层层深入展开论证。

# 第五单元·口语交际 讨论

## 摘要
本次口语交际训练「讨论」。讨论是就某些问题与他人表达意见、寻求共识或解决问题的交流方式。讨论的原则可以概括为十二个字：紧扣议题，言无不尽，包容合作；并要遵守一系列具体的讨论规则。

## 十二字原则
1. **紧扣议题**：讨论要围绕议题展开，有的放矢，突出重点，切不可东拉西扯、离题万里——有些小组讨论热火朝天却难有成果，重要原因就是偏题跑题，把讨论变成了漫无边际的聊天。
2. **言无不尽**：每个参与者都要积极发言。不要因为觉得自己「没想好」而缄口不言——讨论本身就是一个从「没想好」逐渐走向「想好」的过程，「不成形」的观点同样闪烁着智慧的火花，大胆说出来才可能互相启发。
3. **包容合作**：出现观点碰撞甚至交锋时，要理性客观地发表意见，坦诚谦虚地对待不同看法，保证讨论在互相信任、互相帮助的氛围中进行。讨论其实就是合作「避短」、共同「扬长」的过程。

## 讨论规则（教材表格）
| 讨论规则 | 简要说明 |
| --- | --- |
| 预先公布相关要求 | 讨论前明确目的、问题、注意事项等，要求要具体、明确、有可操作性 |
| 主持人保持中立 | 遵照规则裁判并执行程序，尽可能不发表自己的意见，不表现出倾向性 |
| 参与者发言机会均等 | 尽量让所有参与者都有发言机会，意见不同者也有表达观点的权利 |
| 发言的观点要明确 | 明确表达对相关问题的意见，赞成还是反对他人观点也应表述清楚 |
| 发言时间与次数受限 | 每人每次发言不能太长，同一问题发言次数不宜太多，不能搞一言堂 |
| 不同问题依次讨论 | 不得偏离当前讨论的问题；一个问题讨论完毕再讨论下一个 |
| 就事论事，文明表达 | 不得进行人身攻击，不得质疑他人的动机、习惯或爱好 |
| 尊重发言的完整性 | 不能随便打断他人的发言 |

我国民主革命的先行者孙中山先生很重视这些规则，视之为开民智、聚民力的重要基石。

## 口语实践（教材题目）
一、某中学准备在校园中安放名人塑像，学生会向同学们征求意见。讨论记录示例：甲主张放孔子、孟子、老子、庄子、司马迁等古代文化名人塑像；乙用「干脆穿长袍来上学」讥讽甲，进行人身攻击；丙补充不能只有古代名人，托尔斯泰、爱因斯坦的塑像也可以考虑；丁建议思路打开些，革命先烈、英雄模范的塑像也应在校园占有位置。——评价：甲观点明确但面窄；乙违反「就事论事，文明表达」的规则；丙、丁紧扣议题、补充完善，表现良好。
二、任选一个问题（怎样才算「有教养」？中学生上学应不应该带手机？）以小组为单位讨论，整理讨论报告并在全班展示。提示：思路开阔但要有重点；可由一名同学任主持人控制时间、把握节奏；所有参与者主动思考、积极发言，尽量达成共识，也不刻意回避不同意见；用录音、速记记录，讨论后整理成报告。

## 例题
思考题：讨论中同学乙说「你干脆穿长袍来上学得了」，违反了哪些讨论规则？
解答：①「就事论事，文明表达」——乙讥讽挖苦甲，偏离了对塑像方案本身的讨论，近乎人身攻击；②「发言的观点要明确」——乙没有明确表达自己对塑像人选的意见，只是情绪化地否定对方。正确的做法是理性指出只放古代名人塑像的不足，并明确提出自己的建议。

## 练一练
1. 填空题：讨论的原则大致可以概括为十二个字：紧扣议题，（　　　　），包容合作。
2. 判断题：讨论时觉得自己「没想好」就最好不要发言，以免说错。（　）
3. 简答题：主持人在讨论中的基本职责是什么？

## 参考答案
1. 言无不尽
2. 错（讨论本身就是一个从「没想好」逐渐走向「想好」的过程，每个参与者都要积极发言）
3. 遵照规则来裁判并执行程序，尽可能不发表自己的意见，不对别人的发言表现出倾向性；同时控制每个人的发言时间，调节现场气氛，把握讨论节奏，避免跑题或陷入无谓的争论。

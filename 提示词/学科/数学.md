# 学科规范：数学

> 与 00-通用规范.md 及任一学段文件拼接使用。

## 概念与公式

1. 概念、性质、法则定义表述准确，符合教材口径；
2. 公式、运算律、关系式一律用 LaTeX：行内 $a + b = b + a$，独立公式 $$c = a^2 + b^2$$；
3. 小学低年级的简单算式（如 $3+4=7$）也统一用 LaTeX 书写，保持全文一致；
4. 单位与符号按教材口径，同一文档内保持一致（如除号与斜杠不混用，以本教材为准）。

## 小节组织约定

每个知识点内的小节顺序建议：
`## 摘要` → `## 概念/法则`（定义与 LaTeX 表达）→ `## 方法步骤`（有序列表分步）→ `## 典型例题解析`（教材例题，如有）→ `## 例题` → `## 练一练` → `## 参考答案`

- 几何与图形内容用文字描述图形特征与关系，不强求作图；分类对比用表格；
- 统计与概率内容照录教材数据（以本教材为准），标注数据出处口径。

## 例题与练一练题型

- 例题：1 道典型题，给出分步完整解答，每一步注明依据（用了哪条法则/性质）；
- 练一练：计算或求解 1 题、概念判断或填空 1 题、应用 1 题；
- 参考答案：给出关键步骤与最终结果，不只给得数。

## 特别注意

- 数学术语首次出现按学段规范处理（小学低年级配生活化解释，初中以上给规范定义）；
- 不引入教材未涉及的解题技巧与超纲方法；
- 应用题情境符合学生生活经验与时代背景。

# 学科规范：历史

> 与 00-通用规范.md 及任一学段文件拼接使用。适用于统编版历史教材（纲要/选择性必修）。

## 教材板块处理规范（核心）

统编历史教材每课由「导入 + 若干子目 + 辅助栏目」构成，处理规则：

1. **子目是正文骨架**：教材每个子目标题（如「列国纷争与华夏认同」）对应一个二级标题 `## {子目标题}`，子目下正文完整整理，不得遗漏该子目的主干史实与因果分析；
2. **学习聚焦融入子目**：「学习聚焦」是教材给出的核心论点，改写为对应子目的开头句或摘要素材，不保留「学习聚焦」字样；
3. **历史纵横与学思之窗**：与主干知识直接相关的，择要融入对应子目作为补充说明，不保留栏目名；纯拓展性的可舍弃；
4. **史料阅读**：每课最多保留 1-2 条关键史料，照录原文并注明出处（如——《汉书·食货志》），放入所属子目末尾，以「史料摘引：」开头；引文不计入篇幅；
5. **思考点 / 问题探究 / 学习拓展**：不照录，其设问可改编为例题与练一练的素材；
6. **单元导语**：单元标题页的导语（阶段特征与学习要求）不单独成块，其要点提炼进本单元各课的「摘要」；
7. **图片与地图**：图注文字（▲ 开头行）与地图图例一律不保留；地图信息缺失不影响文字整理，涉及疆域、格局的表述以教材正文文字为准。

## 表述规范

1. 纪年一律用公元纪年，公元前年份加「公元前」；教材中的年号/朝代纪年首次出现时括注公元年份，如「庆历六年（1046）」；
2. 专有名词（人名、地名、官制、条约、会议、文献）首次出现用全称；古籍引文照录原句，不改写；
3. 制度、条约、政策等成对比照的内容优先用 Markdown 表格（表头须在同一知识块内）；
4. 评价性结论以教材口径为准，不引入教辅观点；教材数据或细节提取不确时，改为通用表述并注明「（以本教材为准）」；
5. 历史学科一般不使用 LaTeX 公式；年代、数量直接用半角数字书写，如「公元前 221 年」。

## 小节组织约定

每个知识点（课）内的小节顺序：
`## 摘要` → `## {子目一}` → `## {子目二}`（依教材子目数）→ `## 知识整合`（可选：本课时间轴或线索表格）→ `## 例题` → `## 练一练` → `## 参考答案`

## 例题与练一练题型

- 例题 1 道：材料分析题（给一段史料 + 设问）或选择题，给完整解答与分析思路；
- 练一练 2-3 道：至少 1 道材料分析或综合论述题，可搭配 1-2 道选择题/填空题；
- 论述题答案给「观点 + 史实论据 + 结论」的要点式示例；选择题答案附简短解析。

## 特别注意

- 每课一级标题格式 `# 第X单元·{课序号} {课名}`；朝代、事件、制度等检索关键词尽量出现在标题或摘要前两句；
- 关键史料与古籍引文的照录部分不计入篇幅上限；
- 活动课（如「家国情怀与统一多民族国家的演进」）作为一个知识点：整理活动主题、任务与要求，例题/练一练可改为活动成果示例，篇幅可下浮至 1000 字左右。

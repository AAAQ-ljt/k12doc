# 学科规范：科学

> 与 00-通用规范.md 及任一学段文件拼接使用。
> 覆盖小学科学（人教鄂教版、教科版、苏教版等各版本教材）与初中科学课程。

## 教材板块保留规范（核心）

1. **观察与探究活动完整保留**：科学课的主体是观察、实验、制作与探究——活动目的、材料器材、步骤、现象记录、结论一样不能少；实验步骤用有序列表分步呈现；
2. **记录表与数据**：教材中的观察记录表、实验数据表用 Markdown 表格重建（表头按学科通识恢复），数据照录教材，教材未给出的数据不得编造；
3. **科学概念表述准确**：概念、定义与课程标准口径一致，术语首次出现给一句话解释；
4. **安全提示保留**：涉及电、火、剪刀、化学品、动植物接触的活动，保留教材的安全提示；
5. **单元回顾**：各单元的「单元回顾/整理」作为一个知识点（一级标题）纳入。

## 小节组织约定

每个知识点内的小节顺序建议：
`## 摘要` → `## 观察与现象`（观察对象与现象描述）→ `## 探究活动`（目的/材料/步骤/记录/结论）→ `## 科学概念`（本课核心概念与解释）→ `## 拓展与应用`（生活中的应用，视情况）→ `## 例题` → `## 练一练` → `## 参考答案`

## 例题与练一练题型

- 例题：1 道与本课直接相关的现象解释题或判断分析题，给出完整解答；
- 练一练：判断题 1 题、填空或连线 1 题、简答（解释现象或设计方案）1 题；
- 参考答案：给出要点；开放性设计题给示例方案与评价要点。

## 特别注意

- **学段适配**：小学低年级（1-2 年级）重在观察描述与生活经验，不引入抽象原理；小学高年级引入对比实验与变量意识；初中要求初步的实验设计与数据分析；
- **爱护生命**：涉及动植物观察与养护的内容体现爱护生命的价值观，不出现伤害动植物的操作；
- **图形与表格**：教材插图（植物构造、实验装置等）用文字描述其特征与标注要点，数据表用 Markdown 表格重建；
- **不编造**：实验现象与数据忠于教材，记忆不确切处标注「（以本教材为准）」；
- **版本差异**：各版本教材单元划分差异大，一律以所用 PDF 实际目录为准。

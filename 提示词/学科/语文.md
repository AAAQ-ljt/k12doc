# 学科规范：语文

> 与 00-通用规范.md 及任一学段文件拼接使用。

## 教材板块保留规范（核心）

语文知识文档的价值在于忠实保留教材面貌，以下板块必须完整呈现：

1. **课文原文完整照录**：现代文、诗词、文言文、寓言一律全文照录，不得节选、缩写或改写；个别记忆不完整的句子宁可标注「（以本教材为准）」，不得杜撰续写；
2. **作者与出处注释保留**：「本文作者×××，选作课文时有改动」「本文选自……」等原书注释照录；
3. **会认字 / 会写字**：分「会认字」「会写字」两个小节列出，每个字后附拼音，如：融（róng）；多音字标注全部常见读音；
4. **词语积累 / 读一读记一记**：教材中的词语表、日积月累内容照录；
5. **课后练习照录**：教材课后题原文保留为「课后练习」小节；
6. **古诗与文言文**：保留原文、作者、朝代，逐句给出通俗释义（放「句子理解」小节）；
7. **寓言、故事类课文**：照录之后补「主旨与启发」小节，用 2-3 句话讲清道理。

## 小节组织约定

每个知识点（课）内的小节顺序建议：
`## 摘要` → `## 课文原文` → `## 重点词语理解`（视课文而定）→ `## 生字`（会认字/会写字）→ `## 词语积累`（视情况）→ `## 课后练习` → `## 主旨与启发`（寓言/古诗适用）→ `## 例题` → `## 练一练` → `## 参考答案`

## 例题与练一练题型

- 例题：理解思考题（如「课文写了什么」「你体会到了什么」），给出完整解答；
- 练一练：判断题、填空题（补课文词句）、简答题（理解与表达）各 1 题左右；
- 参考答案：简明给出，开放题给示例答案。

## 特别注意

- 课文照录部分不计入学段篇幅上限，讲解部分遵守学段篇幅；
- 拼音标注格式统一为：字（pīn yīn）；
- 口语交际、习作、语文园地同样各作为一个知识点处理，按其板块（交际要领/情景示例、习作要求/例文、识字加油站/字词句运用/日积月累/我爱阅读）组织。

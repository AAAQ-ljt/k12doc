# 学科规范：信息技术（含人工智能）

> 与 00-通用规范.md 及任一学段文件拼接使用。
> 覆盖义务教育信息科技与高中信息技术（含人工智能通识内容）。小学低年级一般无独立信息科技教材，如确需使用，按小学低年级学段规范弱化术语。

## 内容组织规范

1. **概念定义**：与课程标准口径一致，术语首次出现给一句话定义；
2. **原理与操作步骤**：一律用有序列表分步；算法与过程可配文字版流程描述；
3. **对比与分类**：优先用表格（如机器学习三种方式的对比、输入设备的分类）；
4. **示例代码**：Python 用以 python 标注语言的围栏代码块；图形化编程（Scratch/积木）用文字描述积木组合，如「重复执行（…）内嵌如果…那么…」；
5. **生活与校园实例**：每个核心概念至少 1 个贴近学生生活的实例；
6. **信息社会责任**：涉及数据、网络、AI 的单元，补一节隐私保护、安全用网、AI 伦理要点（2-4 条）；
7. **不编造产品与链接**：不写具体的下载地址、账号、价格等易过期信息（以本教材为准）。

## 小节组织约定

`## 摘要` → `## 概念/原理` → `## 步骤/方法` → `## 对比与分类`（视情况）→ `## 示例`（代码或活动）→ `## 信息社会责任`（视情况）→ `## 例题` → `## 练一练` → `## 参考答案`

## 例题与练一练题型

- 例题：1 道概念辨析或流程/操作题，给出完整解答；
- 练一练：判断 1 题、简答或排序 1 题、思考/实践 1 题；
- 参考答案：给出要点；实践题给完成标准。

## 特别注意

- AI 通识内容（数据、传感器、机器学习、算法）与学段匹配：小学重体验与现象，初中重过程与原理，高中重思想与系统；
- 涉及真实工具（语音识别、图像识别等）描述其通用能力，不承诺具体效果。
